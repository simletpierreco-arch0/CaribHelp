# CaribTech Student Hub

A responsive front-end starter for a school student portal, built with plain HTML, CSS and JavaScript. It is designed as a foundation for a Caribbean school hub.

## Features
- Responsive student dashboard layout
- Overview cards, sample assignment list and daily schedule
- Navigation for classes, assignments, study resources and calendar
- Mobile navigation and dark-mode toggle
- No build tools, package installation or API keys required

## Run locally
1. Clone or download this repository.
2. Open `index.html` in a modern browser.

For a local development server, use VS Code's Live Server extension or run `python -m http.server 8000` from the project directory, then visit http://localhost:8000.

## Deploy with GitHub Pages
1. Open the repository on GitHub and go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)`, then save.
4. Wait for GitHub Pages to publish the site. Its URL will appear in the Pages settings.

## Important
This is a front-end demonstration with sample timetable and assignment data. It does not yet include student authentication, a database, real grade records, or teacher/admin tools. Before using real student information, connect a secure backend, add role-based access, and follow school-approved privacy and data-retention practices. Never commit passwords, API keys, or private student data.
